# VET RECORD V1.0.4 MOD

Project rekonstruksi/modifikasi berbasis APK baseline `VetRecord V1.0.4_FINAL.apk`.

## Baseline
- Package: `com.gievetrecord`
- Android native / Kotlin
- Jetpack Compose
- Android Gradle Plugin metadata: `9.3.1`

## Tujuan
Mempertahankan fitur V1.0.4 dan melakukan perubahan terbatas:
1. meningkatkan keandalan Auto-Sync Google Drive;
2. pagination 50 data per halaman pada daftar yang relevan.

Tidak ada penghapusan/perubahan fitur lain tanpa permintaan eksplisit.

## Status
Source Kotlin asli tidak tersedia dari APK. Struktur project sedang direkonstruksi dari DEX, manifest/resources, dan metadata APK. Jangan menganggap repository ini sebagai source resmi pembuat asli.
